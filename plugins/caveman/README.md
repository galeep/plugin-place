# caveman

Caveman: ultra-compressed communication mode (lite/full/ultra/wenyan). Cuts ~75% of output tokens while keeping technical accuracy. Downstream-patched so terseness reads as value-proportional allocation: a floor for low-value turns, not a cap on high-value ones (see patches/caveman.json).

## Provenance

Vendored whole from [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) @ `v2.1.0`.
Licensed under MIT. All credit to the upstream author.

Downstream edits (if any) are applied from `patches/caveman.json` on every build
and fail the build if an anchor no longer matches upstream. This directory is
generated by `scripts/build.sh`; edit `patches/caveman.json`, not these files.
